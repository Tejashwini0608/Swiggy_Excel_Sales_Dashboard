# 🍽️ Swiggy Sales Analysis Dashboard (Excel Project)

## 📌 Project Overview
This project focuses on analyzing Swiggy food delivery sales data using Excel to generate business insights and interactive dashboard reports.

---

## 🎯 Objectives
-Analyze sales and order performance
-Track customer ratings and revenue trends
-Identify top-performing cities and food categories
-Support business decision-making using data visualization

---

## 🛠 Tools Used
-Microsoft Excel
-Pivot Tables
-Pivot Charts
-Slicers
-Data Cleaning
-Dashboard Design

--

## 📊 Dashboard Features
-Total Sales KPI
-Average Rating KPI
-Average Order Value
-Total Orders & Rating Count
-Monthly Sales Trend
-Daily Sales Trend
-Weekly Sales Trend
-Sales by State (Map Visualization)
-Sales by Food Type
-Top 5 Cities by Sales

--

## 📈 Key Insights
-Certain states contribute significantly higher revenue
-Weekends show higher sales compared to weekdays
-Veg food category generates major revenue share
-Top cities contribute large percentage of total sales
